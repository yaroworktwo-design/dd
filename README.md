# Дымок и Милена — демо (этап 1)

3D-приключение про двух котов, потерявшихся в Бруклине. Движок — **Three.js + TypeScript + Vite** (WebGL 2).
Модели котов генерируются скриптом в **Blender 4.2** (`tools/blender/make_cats.py`).

## Почему такой движок

В среде разработки нет Unity/Unreal (нужны лицензии и GUI) и нет macOS/Xcode. Вариант, который можно честно
собрать, запустить и проверить здесь, — WebGL-игра:

- **Windows**: запускается в Chrome/Edge (клавиатура и мышь, геймпады).
- **iOS**: запускается в Safari, можно «Добавить на экран Домой» (полноэкранный режим, экранный джойстик).
- Позже тот же код можно завернуть в нативное приложение (Tauri/Electron для Windows, Capacitor для iOS).
  Для iOS-сборки нужен Mac с Xcode, здесь его нет.

## Запуск

Нужен [Node.js LTS](https://nodejs.org/) (20+).

```bash
npm install
npm run dev        # http://localhost:5173
```

Играть в браузере: **https://yaroworktwo-design.github.io/dd/**

Локально на Windows: двойной щелчок по `play-windows.bat` (ставит зависимости, запускает сервер и открывает браузер).

iPhone/iPad в той же Wi-Fi-сети: откройте в Safari адрес `http://<IP-компьютера>:5173`. Для слабых устройств в паузе
есть «Шерсть: Низкое».

Готовая сборка: `npm run build` → папка `dist/`, раздаётся любым статическим сервером (`npm run preview`).

## Режимы игры

- **Одиночная игра**: вы управляете обоими котами. Tab или клик по портрету слева переключает кота
  (камера перелетает к нему, с эффектом и звуком). G — «за мной / жди» для второго кота.
- **Онлайн до 3 игроков** (без разделения экрана): «Создать комнату» → кнопка «Скопировать ссылку» →
  друзья открывают ссылку или вводят 5-значный код. Хозяин комнаты — Дымок, второй игрок — Милена,
  третий — Пиксель. Сюжет, босс, рыбки и лифт общие. Связь идёт напрямую между браузерами (WebRTC/PeerJS),
  отдельный сервер не нужен. В очень строгих сетях (корпоративный NAT) прямое соединение может не установиться.
- `?q=low` в адресе включает облегчённую графику для слабых ПК и телефонов (то же самое есть в паузе).

## Управление

| Действие | Клавиши |
|---|---|
| Шаг / рысь | WASD (лёгкий наклон стика — шаг) |
| Галоп / красться | Shift / Ctrl или C |
| Камера | мышь (клик по игре — захват курсора) |
| Прыжок | Пробел |
| Удар / умение | ЛКМ или F / Q |
| Действие | E |
| Паутина (держать) | ПКМ или R |
| Сменить кота / приказ | Tab или портрет / G |
| Вид от 1-го лица | V |
| Сардины / пауза | H / Esc |

Геймпад поддерживается. На iPhone/iPad — экранный джойстик и кнопки.

## Графика

- **Коты** (Blender, `tools/blender/make_cats.py`): скульпт → ремеш → UV-развёртка; окрас запекается в текстуру
  1024 px (полоски табби, дымчатые пятна, очки вокруг глаз, подводка, рот). Глаза с нарисованной радужкой
  и влажной роговицей. Скелет с IK-лапами: шаг (латеральная последовательность), рысь (диагональные пары),
  галоп и подкрадывание собраны из траекторий лап — лапы стоят на земле, а не скользят — и запечены в анимации.
- **Шерсть**: 16 слоёв (shell fur) с зачёсом вдоль тела, сглаженными краями (alpha-to-coverage + MSAA),
  без меха на глазах и носу, с подсветкой силуэта для тёмных котов.
- **Город**: фасады с настоящей глубиной (откосы окон, подоконники, перемычки, пояса, карнизы с кронштейнами,
  водостоки, кондиционеры, на которые можно запрыгнуть), комнаты за окнами, ряд браунстоунов с крыльцами,
  деревянный пол в лавке, небо с облаками. Пост-обработка: GTAO, bloom, цветокоррекция.

## Пересборка моделей котов

```bash
BLENDER=/путь/к/blender npm run models        # все коты и голубь -> public/models/*.glb
BLENDER=/путь/к/blender npm run models milena # только один кот
```

`tools/blender/render_preview.py` рендерит модель с четырёх ракурсов для проверки.

## Структура

- `src/game/game.ts` — игровой цикл, игроки и сплит-скрин, катсцены, задания, магазин, сохранения.
- `src/game/world.ts` — локации, коллизии, интерактивные объекты.
- `src/game/cat.ts`, `fur.ts` — коты, анимации, управление, паутина, костюмы, шерсть.
- `src/game/boss.ts` — ИИ Карниза.
- `src/engine/` — физика, ввод (клавиатура, мышь, геймпад, сенсор), процедурная музыка и звуки, текстуры.
