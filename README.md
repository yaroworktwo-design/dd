# Дымок и Милена — демо (этап 1)

3D-приключение про двух котов, потерявшихся в Бруклине. Движок — **Three.js + TypeScript + Vite** (WebGL 2).
Модели котов генерируются скриптом в **Blender 4.2** (`tools/blender/make_cats.py`).

## Почему такой движок

В среде разработки нет Unity/Unreal (нужны лицензии и GUI) и нет macOS/Xcode. Вариант, который можно честно
собрать, запустить и проверить здесь, — WebGL-игра:

- **Windows**: запускается в Chrome/Edge (клавиатура и мышь, геймпады).
- **iOS**: запускается в Safari, можно «Добавить на экран Домой» (полноэкранный режим, экранный джойстик).
- Позже тот же код можно завернуть в нативное приложение (Tauri/Electron для Windows, Capacitor для iOS).
  Для iOS-сборки нужен Mac с Xcode, здесь его нет.

## Запуск

Нужен [Node.js LTS](https://nodejs.org/) (20+).

```bash
npm install
npm run dev        # http://localhost:5173
```

Windows: двойной щелчок по `play-windows.bat` (ставит зависимости, запускает сервер и открывает браузер).

iPhone/iPad в той же Wi-Fi-сети: откройте в Safari адрес `http://<IP-компьютера>:5173`. Для слабых устройств в паузе
есть «Шерсть: Низкое».

Готовая сборка: `npm run build` → папка `dist/`, раздаётся любым статическим сервером (`npm run preview`).

## Игроки: 1, 2 или 3

| | Игрок 1 | Игрок 2 | Игрок 3 |
|---|---|---|---|
| Кот | Дымок (в одиночке — Дымок и Милена с переключением) | Милена | Пиксель |
| Ходьба | WASD | Стрелки | Numpad 8 4 5 6 |
| Камера | мышь (клик — захват) / Z X | [ ] | Numpad / * |
| Прыжок | Пробел | Enter | Numpad 0 |
| Бег / красться | Shift / Ctrl или C | правый Shift / `/` | Num + / Num . |
| Удар | ЛКМ / F | `.` | Numpad 7 |
| Действие | E | `;` | Numpad 9 |
| Умение | Q | `,` | Numpad 1 |
| Паутина (держать) | ПКМ / R | `'` | Numpad 3 |
| Вид от 1-го лица | V | `\` | Numpad − |

Геймпады: 1-й геймпад управляет игроком 1, 2-й — игроком 2, 3-й — игроком 3.
В одиночной игре: Tab или портреты слева — сменить кота, G — «за мной / жди», H — съесть сардины, Esc — пауза.

## Что есть в демо

**Готовые механики (работают в запущенной игре):**

- Коты из Blender: Дымок (упитанный, дымчатый, оливковые глаза), Милена (стройная серебристая табби), Пиксель
  (смокинг, 3-й игрок), Карниз (рыжий босс, рваное ухо), Пломбир (белый перс, продавец). У каждого своя сетка,
  окрас, скелет и анимации: ожидание, ходьба, бег, красться, прыжок, удар, шипение, сидеть.
- Шерсть — 12 слоёв shell-fur поверх модели (не «пластилин»), вибриссы, блестящие глаза.
- Режимы на 1, 2 и 3 игрока, разделённый экран.
- Камера от 3-го лица, не проходит сквозь стены, плюс вид от 1-го лица.
- Двор Бруклина с паркур-маршрутом «ящик → мусорка → забор → навес → пожарная лестница → крыша».
- Подвал с совместной задачей: рывок Дымка сдвигает решётку, Милена пролезает в щель и открывает защёлку.
- Грузовой лифт на крышу, голубятня с тайником, паутинные браслеты (раскачка с сохранением инерции).
- Босс Карниз: замах со знаком «!», ложные выпады, удары лапой, окна уязвимости («звёздочки»).
  Шипение Милены ослепляет его, рывок Дымка бьёт сильнее.
- Лавка Пломбира: примерка, цена × количество = итог, покупка костюмов («Бруклин», «Ночной герой»,
  «Искательница», «Звёздная») и сардин. Общий кошелёк рыбок.
- Катсцены с субтитрами и юмором (вступление Дымка, переезд Милены, встреча, босс, победа), пропуск по Enter/Esc.
- 8 процедурных саундтреков (двор, подвал, крыши, босс, магазин, комедия, нежная тема, меню) и синтезированные
  звуки («мяу» разной высоты, шипение, голуби).
- Живая локация: голуби разлетаются, машины ездят по улице, сохнущее бельё, пар из вентиляции, неон, гирлянды,
  дождь во вступлении, панорама города и мост, коробка-укрытие, прятки под машиной.
- Лежанки-чекпоинты, автосохранение в браузере, стрелка задания (отключается в паузе без потери прогресса).

**Временные ассеты:** здания, мебель, машины и голуби собраны из примитивов и процедурных текстур.
Модели котов — процедурные (метаболы + ремеш + авто-скиннинг) и пока проще, чем ручная скульптура.

**Ещё не реализовано:** канализация и стая крыс, Центральный парк, рыбный рынок и Шарик, метро, остальные NPC,
прилипалы/планер/голограмма/магнит/щит, по 5 костюмов на кота, враги-преследователи, нативные сборки
Windows (.exe) и iOS (App Store).

## Пересборка моделей котов

```bash
BLENDER=/путь/к/blender npm run models        # все коты и голубь -> public/models/*.glb
BLENDER=/путь/к/blender npm run models milena # только один кот
```

`tools/blender/render_preview.py` рендерит модель с четырёх ракурсов для проверки.

## Структура

- `src/game/game.ts` — игровой цикл, игроки и сплит-скрин, катсцены, задания, магазин, сохранения.
- `src/game/world.ts` — локации, коллизии, интерактивные объекты.
- `src/game/cat.ts`, `fur.ts` — коты, анимации, управление, паутина, костюмы, шерсть.
- `src/game/boss.ts` — ИИ Карниза.
- `src/engine/` — физика, ввод (клавиатура, мышь, геймпад, сенсор), процедурная музыка и звуки, текстуры.
